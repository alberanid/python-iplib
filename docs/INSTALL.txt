# Requirements

* Python 3.10 or later.


# Install

Using pip:

   pip install .

Or in editable mode:

   pip install -e .

The example scripts `ipconv`, `nmconv`, and `cidrinfo` are installed as console commands into your Python environment's bin directory (their source is in the `iplib_cli` package; they can also be run as e.g. `python -m iplib_cli.ipconv`).


# Build

To build the source distribution and the wheel (written into `dist/`):

   pip install build
   python -m build

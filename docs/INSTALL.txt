# Requirements

* Python 3.10 or later.


# Install

Using pip:

   pip install .

Or in editable mode:

   pip install -e .

The example scripts `ipconv`, `nmconv`, and `cidrinfo` are automatically installed into your Python environment's bin directory.


# Build

To build the source distribution and the wheel (written into `dist/`):

   pip install build
   python -m build
